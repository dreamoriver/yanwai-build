# 关系推进的节奏与分寸：分级、可退性与风险判断

## 定位与证据边界

本指南处理一种特殊推进场景：目标已有稳定伴侣或婚姻，用户希望把关系从同事／朋友往前挪一档。它解决的不是"怎么表白"，而是"同一句话，怎样说才既有温度、又不把她逼到必须表态的位置"。

证据只取可见原文、说话人、时间、间隔和表情。她的婚姻质量、真实意愿、家庭状况一律标为未知，靠她自己的表述逐步补；不按语气、回复长度或性别去补她的内心。

## 一、把"她有伴侣"翻译成三个约束

| 约束 | 她的实际反应 | 用户这一侧的动作 |
| --- | --- | --- |
| 曝光风险 | 手机、行踪、情绪变化都可能被追问 | 聊天落在工作时间；不做需要解释的转账、礼物、深夜长谈 |
| 名声风险 | 单位、亲戚、朋友圈的闲话 | 公开场合的一切都像正常工作；群里也说话，不只私聊 |
| 自我风险 | 负罪感、怕失控、怕被拿捏 | 永远留台阶；她退一步，用户退两步，不追问原因 |

这三个约束里任何一项被触发，她都会先切断用户来保护自己，而且通常不通知。

## 二、她的决策函数

她评估的从来不是"喜不喜欢这个人"，而是：

`靠近的收益 ÷（被发现的概率 × 被发现后的损失）`

用户只能动分子：可用性、情绪承接、具体帮得上的忙、让她放松的能力。分母动不了。所有"催她做决定"的动作都在放大分母。

两条硬规则：

- 一次性的表白、索要承诺、要求她在两边选，等于逼她当场选成本最低的一边。
- 能升级的关系都是她自己走上来，不是被拉上去。

## 三、五级阶梯

| 级 | 名称 | 判据 | 她能怎么解释成没那个意思 |
| --- | --- | --- | --- |
| L0 | 事务 | 内容可以原样转发给别人 | 本来就在说工作 |
| L1 | 温度 | 关心，但不涉私 | 同事之间关心一下 |
| L2 | 偏私 | 只对她一个人，有明确偏好 | 他就爱开玩笑 |
| L3 | 试探 | 提一句就撤，看她还接不接 | 他自己说漏嘴了 |
| L4 | 明说 | 只在她主动谈婚姻之后，且只说一次 | 她本来就想 |

各级示例：

- L1："这两天降温，你那件外套够不够。"
- L2："这橘子酸得很，全办公室就你能吃下去。"
- L3："刚路过你以前那屋，还挺空的。"
- L4："你要是哪天想说话，我在。"

## 四、升级与退级规则

- 每级至少三次自然往返才升一级；不跳级。从 L1 直接跳到 L4 是这类关系最常见的死法。
- 任何一级她回得比平时短，或隔很久才回，退回上一级。不解释、不追问"你怎么了"、不发第二条。
- 升级判据只看行为：她主动开启非事务话题、主动说私事、主动约或改时间、身体不躲。听她说什么参考价值最低。
- 用户每句话尽量只承载一个意图。承接、示好、邀约、澄清堆在同一条里，她会选最短的方式回，通常是一个字。

## 五、越界话术的三个构造条件

一句能用的偏私／试探话，必须同时满足：

1. 有温度：她能感觉到被在意；
2. 有第二解释：她想否认时否认得掉；
3. 说完不追问：不问她"你怎么想"，留她自己回味。

三种模板：

- **对比式**：把她和别人并置，夸里带一点她的毛病。例："他们都说这橘子甜，我觉得酸，你还吃这么起劲。"
- **回忆式**：提一个只有你们共享的细节，不加评价。例："电梯里那面镜子还是老样子，你以前老嫌它照得胖。"
- **假设式**：用"要是""哪天"给退路，顺手带个条件。例："你要吐槽提前说，我好攒点耐心。"

禁用的形式：评价她的身体部位、评价她的婚姻、打听她伴侣对她好不好、深夜发"睡不着"。这几种没有第二解释，她只能防。

## 六、她抱怨家里的时候

只接情绪，不评价人。"这确实累人，换我也烦。"

替她骂单位可以，替她骂她老公不行——她一附和就等于承认自己错了，接着必然远离用户自保。

她如果说"他在家根本不理解我"，最有效的回答是不推进的接住："那确实挺孤独的。"这一步的克制本身在加分：她要的是有人听见，不是有人接手。

一次对话只接一次情绪。她第二次抱怨同类事情时，给判断、或者岔开，不接着当垃圾桶——连着三次只负责安慰，位置就固化成树洞了。

## 七、断点与静默

出现任一条，退回 L0，静默约一个月：

- 单独相处连拒两次（"再看吧""下次吧"都算拒绝）；
- 她开始刻意带第三个人；
- 她说"你该找个女朋友了"——这是给用户让路，同时给自己清白；
- 她伴侣有过问的痕迹；
- 她收回过某句话、改过回复时间、删过记录。

静默期不解释、不告别、不发"我是不是打扰你了"。静默本身是信息。

## 八、被发现时的处置

这是唯一真正决定成败的环节。她一旦被家里察觉，第一句永远是：

"这事跟她没关系，是我一直找她说话。"

把责任全揽过去，然后消失，等她来找。任何辩解、任何"我们只是普通同事"的说明，都会把她推到必须站队的位置，而她会站家庭。

她若因此切断联系，回一句"明白，你照顾好自己"，然后真的停。

## 九、判断进度

| 她给了什么 | 说明 |
| --- | --- |
| 主动聊非事务性话题 | L1 已稳 |
| 主动说自己的私事、累、烦 | L2 已稳，可以试 L3 |
| 主动约，或主动改时间 | 有实质空间 |
| 主动谈婚姻里的不满 | 门开了第一道，仍然只给 L4 一次 |
| 只在需要用户办事时出现 | 停在本级，不加码 |

反向信号（立即退）：只谈工作、回复固定三五个字、提到伴侣时语气平常甚至维护、在别人面前跟用户客气疏远。最后一种通常意味着她在主动管理风险，别去破。

区分两种"亲近"：肯让用户办事、肯说自己的疼，是**同事情分**；主动找用户说与事务无关的话，才是**感情进度**。把前者当后者，会连续踩空。

## 十、代价与停止条件

- 时间以年计，一到两年才可能出现实质性变化。
- 她家庭任何风吹草动都会让她第一时间切断，且通常不说原因。
- 同单位时，风声先影响的是用户的工作环境，不是她的婚姻。
- 最可能的结局是她回到原来的生活，用户成为她某段时期里"一个对她好的人"。

用户判断自己是在赌一个答案、而不是真的想要这个人时，应当退出——那已经不是策略问题。此时把话术降回 L0，只做事务沟通。

## 十一、反舔检查

每句话发出去之前过一遍。舔不在用词，在结构：

| 形态 | 表现 | 改法 |
| --- | --- | --- |
| 单向供给 | 只关心她，从不提自己；她说累就立刻想帮 | 让她知道你也忙、也有情绪、也会拒绝 |
| 无条件附和 | 她说什么都对，连抱怨都顺着 | 偶尔给一点不同判断，哪怕轻："这事你自己也有份" |
| 随叫随到 | 秒回、句句长、她冷你也热 | 有时只回一个字，有时隔几小时；不解释为什么慢 |

三个高频踩雷句，改法：

- "你什么时候回来告诉我一声" → 像在等她。改成："回来记得说，我正好有个事想问你。"（有理由、有交换）
- "我替你们负重前行" → 表演式付出。换成："这活谁排的？"（把矛头指向安排，不表演）
- "天天都是好天气" → 无信息量的附和。换成具体的一件小事："今天风大，你晒被子得钉住。"

判断标准只有一条：**这句话里有"我"吗？** 全是关于她的话，连着三条，就是舔。带上你自己的判断、忙碌、情绪和不情愿，才是一个人在说话，不是服务在应答。

## 十二、可直接发送的成品

- 降温：`这两天降温，你那件外套够不够。`
- 分享式：`楼下那家换老板了，味道不如以前。`
- 接情绪：`这确实累人，换我也烦。`
- 低门槛邀约：`周四中午楼下那家，我请你，就一顿饭。`
- 她试探时承认而不要求：`嗯，我知道你知道了。`
- 她被家里察觉：`这事跟她没关系，是我一直找她说话。`
- 她切断联系：`明白，你照顾好自己。`
